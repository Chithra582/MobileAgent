# Mobile Device Action Execution

## Overview
This skill issues low-level device control commands, translating agent decisions into physical touchscreen and keyboard input events.

## Capabilities
- Executes tap, double tap, long press, and coordinate-directed swipes.
- Types alphanumeric strings and special keys into active input fields.
- Sends hardware system events (Home, Back, Recent Apps, Volume).
