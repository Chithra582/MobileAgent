# Cross-Platform Task Planning

## Overview
This skill breaks down end-user requests into sequential UI sub-tasks, tracking progress against global task objectives.

## Capabilities
- Formulates multi-step operation roadmaps across diverse native mobile applications.
- Manages sub-goal states (pending, in-progress, completed, failed).
- Adapts navigation routes when alternative app pathways or shortcuts are available.
